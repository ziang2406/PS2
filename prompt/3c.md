## Assignment prompt
Implement Question 3(c) in R, extending the code for Question 3(b). Explain each code block and its mathematical purpose.

Goal:
Estimate gamma using two moment conditions and an identity weighting matrix. Report the estimate, its standard error, both pricing errors and their t-statistics, and a joint test that the pricing errors are zero.

1. Prepare and align the data.

   From the EQ Dataset:
       Rw_t = exp(re_t)
       Rf_t = exp(rf_t)
       xRw_t = Rw_t - Rf_t

   Retain monthly observations of annual variables.

   Import the out-of-sample forecasts from Question 2(e) of Problem Set 1. Verify the forecast timing carefully:
       forecast at t-1 must predict xRw_t.

   Do not reconstruct these forecasts using full-sample coefficients.
   If the forecast file is unavailable, identify the missing input.

2. Construct the trading instrument.

   Define:
       sigma_e_squared = unconditional variance of Rw
       z_{t-1} = forecast_{t-1}(xRw_t) / sigma_e_squared

   Use the unconditional variance of the gross market return Rw,
   not the variance of log returns or excess returns.
   Document the sample used to calculate this variance.

   Construct the managed portfolio excess return:
       managed_t = z_{t-1} * xRw_t

   Align by the forecast's target date rather than blindly lagging rows.
   Keep a common complete sample for both moments.

3. Define the two observation-level moments.

       g1_t(gamma) = exp(-gamma * re_t) * xRw_t

       g2_t(gamma) = exp(-gamma * re_t) * managed_t

   Stack them into a 2 × 1 vector:
       g_t(gamma) = [g1_t(gamma), g2_t(gamma)]'

   Calculate:
       gbar(gamma) = colMeans(g_t(gamma))

4. Estimate gamma using identity-weighted GMM.

       W = I_2

       Q(gamma) = gbar(gamma)' W gbar(gamma)
                = mean(g1(gamma))^2 + mean(g2(gamma))^2

   Minimize Q numerically.
   Inspect an objective grid, verify convergence, and check sensitivity
   to numerical search bounds.

   Do not standardize the moments or change W: that would change the
   identity-weighted estimator requested by the assignment.

   Because there are two moments but only one parameter, both sample
   moments generally cannot be set to zero simultaneously.

5. Calculate the 2 × 1 derivative matrix G_hat.

       G1_hat = mean(-re * g1_t(gamma_hat))
       G2_hat = mean(-re * g2_t(gamma_hat))

       G_hat = [G1_hat, G2_hat]'

   Check the first-order condition:
       G_hat' gbar(gamma_hat) ≈ 0

6. Estimate the 2 × 2 long-run covariance matrix S_hat.

   Use the fitted moment series g_t(gamma_hat).
   Center each column before calculating autocovariances.

       Gamma_l = (1/T) * sum_{t=l+1}^T u_t u_{t-l}'

       S_hat = Gamma_0
               + sum_{l=1}^L
                 (1 - l/(L+1)) * (Gamma_l + Gamma_l')

   Use the course's Newey–West bandwidth procedure.
   Document bandwidth, prewhitening, and finite-sample settings.
   Account for overlapping annual observations.

7. Calculate gamma's standard error.

   For W = I_2:
       V_gamma = (G_hat' G_hat)^(-1)
                 G_hat' S_hat G_hat
                 (G_hat' G_hat)^(-1)

       se_gamma = sqrt(V_gamma / T)

   V_gamma is the asymptotic variance of sqrt(T)*(gamma_hat-gamma_0).

8. Calculate pricing errors and their standard errors.

   The pricing-error vector is:
       alpha_hat = gbar(gamma_hat)

   Account for estimation of gamma using:
       P_hat = I_2
               - G_hat (G_hat' G_hat)^(-1) G_hat'

       V_alpha = P_hat S_hat P_hat'

       covariance_alpha = V_alpha / T

   For each moment j:
       se_alpha_j = sqrt(covariance_alpha[j,j])
       t_alpha_j = alpha_hat_j / se_alpha_j

   Do not use sqrt(S_hat[j,j]/T) alone: it ignores estimation of gamma.

9. Test whether both pricing errors are jointly zero.

   Because W is the identity, do not compare T*Q(gamma_hat)
   directly with a chi-squared distribution.

   Instead calculate the Wald statistic:
       J = T * alpha_hat' pinv(V_alpha) alpha_hat

   Use a Moore–Penrose pseudoinverse because V_alpha is asymptotically
   rank deficient.

   Under the null and standard regularity conditions:
       J ~ chi-squared(2 - 1) = chi-squared(1)

       p_value = pchisq(J, df=1, lower.tail=FALSE)

   Check the numerical rank and optimizer accuracy.

10. Report:
    - gamma_hat and its Newey–West standard error
    - market pricing error and its t-statistic
    - managed-portfolio pricing error and its t-statistic
    - joint-test statistic and p-value
    - sample dates, T, bandwidth, and convergence diagnostics

Use the actual data and saved forecasts. Flag boundary estimates or
identification problems before applying conventional inference.
