- Stack the moments into a T × 21 matrix across months and calculate 21 sample average pricing moments:
ebar(gamma) = colMeans(e(gamma))

2. Define the GMM objective function using W = I_21:   
Q(gamma) = ebar(gamma)' W ebar(gamma) = sum(ebar(gamma)^2)
Minimize Q numerically and find gamma_hat. Use optimize() over [-10,10], with numerical tolerance of 10^{-10}. Inspect an objective grid with spacing 0.01. Repeat over [-20,20] and [-50,50] for sensitivity checks.

3. Estimate the G_hat vector using fitted moment gamma_hat:

- Stack these derivatives into a 21 × 1 vector G_hat

4. Estimate the long-run covariance matrix of moment conditions \hat{S}^{HAC} using the fitted moment series e_t(gamma_hat) and centering each column before calculating autocovariances.
- u_t = e_t(gamma_hat) - ebar(gamma_hat)
- Gamma_l = (1/T-l) * sum_{t=l+1}^T u_t u_{t-l}'
- \hat{S}^{HAC} = Gamma_0 + sum_{l=1}^L (1 - l/(L+1)) * (Gamma_l + Gamma_l') (21x21 matrix)

5. Calculate gamma_hat's standard error with W = I_21:

se(gamma_hat) = sqrt(avar(gamma_hat))
