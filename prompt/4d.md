2. Let F_t = xRw_t
As a result, under the unconditional beta pricing model, E[F] = lambda' beta_F. Regressing F_t on itself gives beta_F = 1, thus lambda= E[F]
3. We can then estimate the factor premium vector (lambda) by running an intercept-only regression:
F_t = lambda + e_t

4. Since E_t[F] = beta_F,t' mean(xRw_t), we run the time series regression for each of the 20 decile portfolio j as follows:

se_alpha_hat_j = Newey-West standard error of the intercept
t_alpha_hat_j = alpha_hat_j / se_alpha_hat_j

5. Testing whether a vector of alpha_hat_j is jointly zero using the GRS test
- Define a vector of alpha_hat by stacking alpha_hat_j into a 20x1 vector
- Define a matrix of regression residuals epsilon_hat Tx20 
- Assuming that epsilon_hat_j,t is iid and follows N(0, \sigma_{epsilon}^{2}). 
- Calculate the following variables
Sigma_epsilon = epsilon_hat' * epsilon_hat / T
mean_F = mean(F)
variance_F = mean((F - mean_F)^2)
Check that Sigma_epsilon is positive definite and invertible. 
- Calculate GRS statistics: 
GRS =((T-J-K)/J) *
     (alpha_hat' * inverse(Sigma_epsilon) * alpha_hat) /
     (1 + mean_F^2 / variance_F)
where T = number of observations, J = number of test assets (20) and K = number of factor (1)
- p_value <- pf(GRS, df1 = 20, df2 = T - 21, lower.tail = FALSE) since GRS ~ F-distribution(J, T-J-K)
