Part 2: GMM 
1. Define the SDF
mean_Rw = mean(R_{w,t})
M_t(b) = 1 - b * (R_{w,t} - mean_Rw) (a scalar)

2. Define the moment vector and its sample average:
- For each of the 21 portfolios (1 market portfolio xRw and 20 decile portfolios) during each month t:
e_j,t(b) = M_t(b) * xR_j,t
- Stack the moments into a T × 21 matrix across months and calculate 21 sample average pricing moments:
ebar(b) = colMeans(e(b))

3. Define the GMM objective function using W = I_21:   
Q(b) = ebar(b)' W ebar(b) = sum(ebar(b)^2)
Minimize Q numerically and find b_hat. Use optimize() over [-10,10], with numerical tolerance of 10^{-10}. Inspect an objective grid with spacing 0.01. Repeat over [-20,20] and [-50,50] for sensitivity checks.

4. Estimate the G_hat vector using fitted moment b_hat:
- For each portfolio j: G_j = mean(- (R_{w,t} - mean_Rw) * xR_j,t)
- Stack these derivatives into a 21 × 1 vector G_hat
Check that G_hat' * ebar(b_hat) ≈ 0

5. Estimate the long-run covariance matrix of moment conditions \hat{S}^{HAC} using the fitted moment series e_t(b_hat) and centering each column before calculating autocovariances.
- e_j,t(b_hat) = M_t(b_hat) *  xR_j,t 
- u_t = e_t(b_hat) - ebar(b_hat)
- Gamma_l = (1/(T-l)) * sum_{t=l+1}^T u_t u_{t-l}'
- \hat{S}^{HAC} = Gamma_0 + sum_{l=1}^L (1 - l/(L+1)) * (Gamma_l + Gamma_l') (21x21 matrix)

Follow the same HAC bandwidth procedure as question 3b: centered moments, Bartlett weights, denominator \(T-\ell\), ceiling rounding for pilot and final lags, and no prewhitening.

6. Calculate b_hat's standard error with W = I_21:
var(b_hat) = 1/T (G_hat' G_hat)^(-1) G_hat' \hat{S}^{HAC} G_hat (G_hat' G_hat)^(-1)
se(b_hat) = sqrt(avar(b_hat))

7. Calculate pricing errors for each moment condition and their standard errors.
- Define the estimated pricing error vector: 
alpha_hat = ebar(b_hat)
- Calculate the avar of the estimated pricing error vector: 
K = I_21 - G_hat (G_hat' G_hat)^(-1) G_hat'
avar(alpha_hat) = 1/T K \hat{S}^{HAC} K' 
- For each portfolio j: 
se_alpha_hat_j = sqrt(avar(alpha_hat)[j,j])
t_alpha_hat_j = alpha_hat_j / se_alpha_hat_j 

7. Hypothesis testing whether 21 pricing errors are jointly zero: 
- Since avar(alpha_hat) is singular, use a  Moore–Penrose  pseudoinverse (P_inverse) and calculate the Wald statistics:  
W_stat = alpha_hat' P_inverse(avar(alpha_hat)) alpha_hat
   
- Under the null hypothesis and regularity conditions, we have W_stat ~ chi-squared(21 - 1) = chi-squared(20) 
- p_value = pchisq(W_stat, df=20, lower.tail=FALSE)

8. Report:
