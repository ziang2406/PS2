## Assignment prompt
1. Using EQ dataset and load the variables rf as the log of the annual deflated R_{f,t} and re as the log of the annual deflated R_{e,t}. Report the sample dataes and number of observations T. 

2. Construct the gross return of the wealth portfolio (Rw) and gross excess return (xRW) for each year and month: 
R_{w,t} = exp(re_t)
Rf_t = exp(rf_t)
xR_{w,t} = R_{w,t} - Rf_t

3. Define the moment function and its sample average: 
e(gamma) = Rw_t^(-gamma) * xRw_t
E[e(gamma)] = mean(e(gamma))

4. Define the GMM objective function: Since we have 1 moment condition and 1 parameter, the weighting matrix W = I and thus, we find gamma that minimizes (E[e(gamma)]^2). Use numerical minimization and report \hat{gamma}, \hat_{E}[e(\hat{gamma})], and \hat_{E}[e(\hat{gamma})]^2 (the objective function).

5. Estimate the \hat{G} matrix using fitted moment \hat{gamma}:
\hat{G} = mean(d e(\hat{gamma})/ d gamma) = mean (-re_t * exp(re_t * -\hat{gamma}) * xR_{w,t})

6. Estimate the long-run covariance matrix of moment conditions \hat{S}^{HAC}: 
e(\hat{gamma}) = Rw_t^(-\hat{gamma}) * xRw_t
u = e(\hat{gamma}) - mean(e(\hat{gamma}))
Gamma_l = 1/T * sum_{t=l+1}^T u_t * u_{t-l}
\hat{S}^{HAC} = Gamma_0 + 2 * sum_{l=1}^L (1 - l/(L+1)) * Gamma_l

where L is the number of autocorrelation lags. Select L using Newey and West (1994): L=\mathrm{const}\cdot T^{1/3} with optimal constant. Report the number of lags, \hat{G}, and \hat{S}^{HAC}

7. Calculate the GMM standard error:
avar(\hat{gamma}) = \hat{S}^{HAC} / (T * \hat{G}^2)
se(\hat{gamma}) = sqrt(avar(\hat{gamma}))

Output: A summary table in tex and csv that reports:
   - \hat{gamma}
   - Newey–West standard error & number of lags in the footnote
   - \hat{G}
   - \hat{S}^{HAC}
   - number of observations and sample period
