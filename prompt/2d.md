## Assignment prompt
Follow the same procedure listed in question 2a,b,c to recover a,b, and M* for the 10 BE_ME decile portfolios, 10 MOM decile portfolios, and 20 combined portfolios (3 cases) using the common sample period. 
For each case, compute the covariance estimator between M* and xR for each portfolio p:
\hat{cov(M*, xR_p)} = 1/T* sum from t = 1 to T of (M_t^* - M_bar) * (xR_p,t - xR_bar) 
in which T is the number of months during the sample period, M_bar and xR_bar is the average value of the sample variable. 

Then, for each case, calculate the estimated pricing errors alpha for each portfolio p:
\hat{alpha_p} = xR_bar + \hat{cov(M*, xR_p)} 

Output: the estimated alpha for each portfolio in each case in table. Portfolios as rows, cases as columns. save the table as latex in figures/2d.tex.
