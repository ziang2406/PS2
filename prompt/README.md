# Problem-set prompts and specifications

Use one Markdown file per problem-set item. Each file begins with the assignment
prompt and provides space for student-authored notes or an empirical design.

For empirical questions, make the design sufficiently detailed before asking AI
to implement code. When relevant, specify data sources, sample restrictions,
variable definitions, timing conventions, transformations, econometric methods,
standard errors, and desired outputs.

Invoke `$tp` at the beginning of every substantive AI request.
